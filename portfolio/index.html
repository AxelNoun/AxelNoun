01lnccbrown/HSSM · Brown University

Fit correct, predictions silently wrong

Problem. HSSM's racing_diffusion_3 likelihood listed its parameters as (A, b, v0, v1, v2, t); the simulator registry it delegates to expected (v0, v1, v2, A, b, t). Model fitting worked. Prior and posterior predictive draws were permuted: mean reaction time 0.88 s instead of 0.337 s, with no error anywhere.

What I did. Aligned the order with the simulator, documented the breaking change for positional callers, and added a test that checks all 21 model/likelihood pairs against the registry so the class of bug cannot return. Log-probabilities match the previous code to 1 ulp.

Result. Merged in two days.

02pytorch/executorch · Meta

One .pte for prefill and decode

Problem. In ExecuTorch's MLX backend, whether MoE expert indices were sorted was fixed at export time. Prefill wants sorted indices (coalesced gather_mm); decode wants them unsorted (no argsort). Teams needed two exported models or accepted the overhead.

What I did. Two custom ops decide at runtime. A new optional FlatBuffer field was appended last so existing .pte files still load; the C++ interpreter prefers it and falls back to the static flag. I also fixed a serialization failure and, with the maintainer, traced a wrong result to a stride bug in Apple's MLX matmul.cpp, patched locally and upstream.

Why it was hard. Three layers (Python builder, schema, C++ runtime), binary compatibility, a bug in a dependency — and no Mac: the macOS CI was my only Metal test bench. The linter and MLX tests went red mid-review; I fixed them. One early hypothesis of mine was wrong and I said so.

Tested locally. Improves Qwen3.5 perf from 73 tok/sec to 80 tok/sec. Great job!Scott Roy (Meta), maintainer — PR #20685

04brian-team/brian2

A sampler wrong for p > 0.5, for years

Problem. Brian2 generates Cython from templates. The BinomialFunction template substituted p where the inversion algorithm needs P = min(p, 1−p): wrong distribution for p > 0.5 (mean 9.11 instead of 8 for n = 10, p = 0.8), a defect dating back years. Constants written with 15 decimals rounded (1−P)^n to zero, so the generated loop never terminated.

What I did. Filed the issue with three quantified defects, then a PR: correct symbol, constants via repr(float(x)), a code-generation-time check that refuses subnormal (1−P)^n with a clear error, a test comparing the sampled distribution against the exact pmf, and a test for the guard. Separately, I found a dangling pointer in the Cython RNG buffer (#1893); my fix, #1896, was merged on 2026-10-20.

05ml-explore/mlx-lm · Apple

A GPU race diagnosed without a GPU

Problem. Fused Metal KL/JS-divergence kernels used in distillation overflowed to −3.39e38 in the backward pass for models above ~1B parameters. The reporter suspected a sentinel value and fast-math.

What I did. Read the kernels: one threadgroup buffer was reused for the max exchange and the sum exchange with no barrier between them. Fixed the barriers (mem_none → mem_threadgroup, one added), masked the tail, guarded fast::exp, replaced an overflowing log(1+exp(x)) with a stable softplus, and wrote regression tests that run the kernel many times. On GitHub's macOS runners: 50/50 nondeterministic runs before, 0/50 after.

Result. Another user reproduced the fix on an M5 Max: 26/50 → 0/50 mismatches, training completes, perplexity 9.21 vs 9.45 on the reference path. The maintainers closed the PR citing review capacity, not its content; I list it because the diagnosis was independently confirmed.

CI that stayed green when the command failed

The same work, on your project. I come in the way I come into an open-source repository: I read your code and its conventions, find what is wrong, open a fix with its tests, and say what I did not verify. Four ways to start:

Targeted correctness fix

3–8 days · fixed price

How I work

  • Test plans state what they did not exercise, with negative controls — see #22372 and #22373.
  • I follow the host project's conventions: Buck targets beside the existing ones, FlatBuffer fields appended for wire compatibility, design reversed when a maintainer asks.
  • I correct myself in public: a wrong hypothesis acknowledged in #20685, a PR withdrawn eight minutes after opening when two of its claims did not hold.
  • I use AI coding assistants and disclose it in every commit. What you pay for is the diagnosis, the direction and the verification.
  • Windows workstation, no Apple or NVIDIA hardware: GPU work is validated through upstream CI and third-party reproduction, and I say so before taking a job that needs more.

Travailler ensemble

Le même travail, sur votre projet. J'arrive comme j'arrive dans un dépôt open source : je lis votre code et ses conventions, je trouve ce qui est faux, j'ouvre un correctif avec ses tests, et je dis ce que je n'ai pas vérifié. Quatre façons de commencer :

Diagnostic d'intégrité d'évaluation

5 jours · forfait

Vos métriques mesurent-elles ce que vous croyez ? Fuites à chaque niveau, fuite temporelle, reproductibilité à la graine, validité des caches. Rapport, script de reproduction, tests ajoutés à votre CI.

Ingénierie d'évaluation et de tests

régie · 20–40 h/semaine

Métriques reproductibles, contrôles de contamination, tests qui échouent sur une régression injectée, rapport hebdomadaire d'une page.

Correctif ciblé

3–8 jours · forfait

Un résultat faux, non déterministe ou dépendant de la machine : cause racine, correctif minimal, test qui échouait avant et passe après, note de ce qui n'a pas été vérifié.

Migration de pile scientifique

1–3 semaines · forfait

pandas 3, NumPy 2, Python 3.14, Cython 3, extras et wheels cassés. CI verte à la fin ; chaque changement de comportement listé avec son effet.

Méthode

  • Mes plans de test disent ce qu'ils n'ont pas exercé, avec des contrôles négatifs — voir #22372 et #22373.
  • Je suis les conventions du projet hôte : cibles Buck à côté des existantes, champs FlatBuffer ajoutés pour la compatibilité, design inversé quand un mainteneur le demande.
  • Je me corrige en public : hypothèse fausse reconnue dans #20685, PR retirée huit minutes après ouverture quand deux affirmations ne tenaient pas.
  • J'utilise des assistants IA et je le déclare dans chaque commit. Ce que vous achetez est le diagnostic, la direction et la vérification.
  • Poste Windows, sans matériel Apple ni NVIDIA : le travail GPU est validé par les CI des projets et par reproduction tierce, et je le dis avant d'accepter une mission qui exige plus.
